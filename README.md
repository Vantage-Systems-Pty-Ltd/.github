# .github

Org-wide GitHub defaults for Vantage Systems: issue forms, PR template, contributing guide,
security policy.

This repository must stay **public**: GitHub applies these defaults to every repository in
the org that lacks its own copy, public or private, but only from a public `.github`
repository.

Handing a repository to Vantage Systems? See [Transferring a repository to us](CONTRIBUTING.md#transferring-a-repository-to-vantage-systems).
