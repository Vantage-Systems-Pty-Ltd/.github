# Security policy

## Reporting a vulnerability

Do not open a public issue.

Use GitHub's private vulnerability reporting on the affected repository (Security → Report
a vulnerability) so the report stays with the code. If that is not enabled on the repository,
contact the organisation owners through the Vantage Systems organisation profile on GitHub.
We will acknowledge within 5 business days.

## Scope

Our repositories are private. This policy exists so an external reporter who finds an issue
in a public artefact — this repo, a deployed site, or a published package — has a channel
that is not a public issue tracker.
